안녕하세요! 어떤 도메인의 기술 로드맵을 그려드릴까요?

📝 자연어 한 문단에 다음 정보를 다 녹여 적어주세요 — LLM 이 자동으로 구조화 추출합니다.

필드 필수? 자연어 예시
domain✅ 필수"2nm 파운드리" · "전기차 배터리"
reference_year✅ 필수"2030년까지" · "향후 5년"
category_hints선택"EUV, GAA, BSPDN 중심으로"
industry선택"Tier-1 IDM Foundry 입장에서"
objective선택"시장 선점이 목표"
👤 투자 정책 (Investment Policy) — 함께 자연어로 적으면 됩니다
total_budget선택"예산 $5B 규모" · "$10B capex"
risk_appetite선택"위험 선호도 균형" · "공격적 베팅"
investment_horizon선택"단기·장기 균형" · "장기 위주"
strategic_priority선택"first-mover, 시장 확장 우선"

📌 예시 1 — 최소 입력 (필수만):
"삼성의 반도체 분야의 2025년부터 2030년까지 예산 50B 정도로 로드맵을 그려줘"
→ domain, reference_year, total_budget 자동 추출. 나머지 정책은 기본값.

📌 예시 2 — 풀 입력 (모든 필드 자연어에 포함):
"Tier-1 IDM Foundry 입장에서 2030년까지의 2nm 파운드리 로드맵을 EUV·GAA·BSPDN 중심으로, 시장 선점을 목표로. 예산 $5B 규모, 위험 선호도 균형(medium), 투자 horizon 균형(balanced), 전략 우선순위는 단기 사업화 + 기반 기술 + 장기 베팅의 균형으로 그려줘"
→ 9개 필드 모두 자동 추출. Active Agents 토글만 별도 선택.
